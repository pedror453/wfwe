# Кермо — ERP автодилера

> Уточнене завдання від 17.10.2026: [брендований інсталятор наявної платформи без розробки нового клієнта](docs/ERP_AutoDealer_Agent_Prompt_UA.md). Такий пакет ще не зібрано; опис нижче стосується раніше створеного окремого клієнта «Кермо».

Мета: сучасний україномовний клієнт для ERP автодилера на 1С:Підприємство зі збереженням даних і бізнес-логіки 1С та безпечною підготовкою переходу з 8.1 на підтримувану 8.3.

> Статус: **ранній етап**. Репозиторій публічний, тому тут лише знеособлений код, контракти й документація загального характеру. Матеріали аудиту, метадані й код конфігурації замовника, журнал робіт, секрети й копії баз зберігаються на сервері замовника, поза репозиторієм.

## Структура

```
source/client/      веб-інтерфейс (React + TypeScript + Vite), тести, e2e
source/desktop/     оболонка Windows-програми (Electron), інсталятор NSIS, графіка, скрипти збірки й перевірки
source/mock-server/ мок-шлюз із синтетичними даними (для розробки й тестів інтерфейсу)
server/             контракт шлюзу (openapi.yaml), шлюз до 1С 8.1 (C#, x86), модулі для 1С
migration/          інструменти аудиту, міграції й перевірок
docs/               документація (див. docs/INSTALLER_UA.md)
installer/ build/ assets/   каталоги під фінальну передачу (артефакти збираються на сервері)
```

## Стан функцій

| Компонент | Статус |
|---|---|
| Вхід, огляд, список і картка наряду-замовлення, довідники (читання з копії бази) | працює |
| Шлюз до 1С 8.1 (COM, x86): сеанси, права користувача 1С, ліміт сеансів | працює |
| Windows-програма «Кермо» й фірмовий інсталятор (.exe), портативна збірка | працює (перевірено на тестовій машині, див. `docs/INSTALLER_UA.md`) |
| Запис, проведення й друк документів | не реалізовано |
| Автооновлення, підпис коду інсталятора | не реалізовано |
| Міграція 8.1 → 8.3 | заблоковано (потрібне рішення щодо стенду) |
| Інші модулі (склад, каса, продаж авто) | не реалізовано |
| Контракт `server/openapi.yaml` | чернетка (шлюз вже підтримує `/health`, `/capabilities`, `/work-orders/summary` — буде додано) |

## Версії інструментів

- Node.js 24.x, npm 11.x, Python 3.12.x (інструменти аудиту).
- Клієнт: React 19, Vite 8, TypeScript 7, Vitest 5, Playwright 1.64.
- Windows-програма: Electron 44.8.0, electron-builder 26.15.3, NSIS 3.0.4.1.
- Шлюз: компілятор `csc` із .NET Framework 4.x (є в Windows), платформа x86.

## Збірка

- Клієнт: `cd source/client && npm ci && npm run build && npm test`.
- Windows-інсталятор: кроки й вимоги в `docs/INSTALLER_UA.md`, розділ 10.
- Шлюз: `server/gateway/build.cmd`.

Повні кроки відтворення збірки на чистій машині доповнюватимуться з кожним етапом.
