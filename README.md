# ERP AutoDealer — новий клієнт (каркас проєкту)

Мета: сучасний україномовний Windows-клієнт для ERP автодилера на 1С:Підприємство зі збереженням даних і бізнес-логіки 1С та безпечною підготовкою переходу з 8.1 на підтримувану 8.3.

> Статус: **ранній етап (аудит і дослідження інтеграції)**. Репозиторій публічний, тому тут лише знеособлений код, контракт API та документація загального характеру. Матеріали аудиту, метадані й код конфігурації замовника, журнал робіт і робочі інструменти зберігаються на сервері замовника, поза репозиторієм.

## Структура

```
source/     вихідні коди клієнта (поки порожньо)
server/     контракт шлюзу (openapi.yaml), майбутні серверні компоненти
migration/  сценарії міграції, перевірок і відкату (поки порожньо)
installer/  інсталятор (поки порожньо)
build/      збірки та контрольні суми (поки порожньо)
assets/     логотипи й дизайн-ресурси (поки порожньо)
docs/       документація
```

## Стан функцій

| Компонент | Статус |
|---|---|
| Контракт шлюзу `server/openapi.yaml` (заказ-наряд СТО) | чернетка |
| Аудит конфігурації та середовища | частково (звіт зберігається поза репозиторієм) |
| Інтеграція з 1С 8.1 через COM | частково: читання метаданих працює; запис і проведення документів заблоковані (клієнтські конструкції в модулях) |
| Міграція 8.1 → 8.3 | заблоковано: конвертація структури ІБ потребує GUI-кроку або проміжної платформи |
| Клієнт (UI) | не реалізовано |
| Інсталятор, portable-збірка | не реалізовано |

## Версії інструментів

- Середовище розробки: Node.js 24.x, Python 3.12.x.
- Шлюз інтеграції (план): вбудований у Windows компілятор `csc` (.NET Framework 4.x), цільова платформа x86.

Кроки повторної збірки на чистій машині будуть додані з першою збіркою.
