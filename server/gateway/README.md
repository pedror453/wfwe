# Шлюз «Кермо» ↔ 1С:Підприємство 8.1

HTTP/JSON-шлюз між новим клієнтом і 1С 8.1 (COM-з'єднання, x86). Контракт — `../openapi.yaml`.

- Кожен сеанс користувача — окреме COM-з'єднання від імені цього користувача (ролі й права 1С зберігаються); пароль не зберігається.
- Один сеанс = одна ліцензія 1С: ліміт `maxSessions`, автозвільнення через `idleMinutes`.
- Підключення дозволене лише до баз зі списку `allowedInfobases` (за замовчуванням тільки копія `Copymax`).
- Бізнес-дані читаються запитами 1С; у таблиці СУБД шлюз не пише й не звертається до них.
- Конфігурація (`gateway.config.json`, із кодом доступу до бази) лежить лише на сервері й не потрапляє в репозиторій.

Збірка: `build.cmd` → `../../build/KermoGateway.exe`. Запуск: `KermoGateway.exe [шлях до gateway.config.json]`.
Стан функцій: читання нарядів-замовлень і довідників — реалізовано; запис і проведення — див. `../../docs`.
