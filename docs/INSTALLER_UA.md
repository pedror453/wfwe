# Інсталятор і Windows-клієнт «Кермо»

Цей документ описує фірмовий Windows-інсталятор, портативну збірку та правила розгортання. Статус — версія 0.1.0 (режим сумісності з 1С 8.1).

## 1. Що це і чого тут немає

«Кермо» — власна програма для робочих місць: окреме вікно з власним значком, назвою й інтерфейсом українською. Вона підключається до сервера Кермо (шлюз) у вашій мережі; дані й бізнес-логіка залишаються на сервері обліку.

- **На робочих місцях 1С більше встановлювати не потрібно.** Користувачі встановлюють лише «Кермо».
- **Сервер обліку залишається на платформі 1С:Підприємство.** Інсталятор не містить, не змінює, не перепаковує і не приховує компонентів 1С; платформа працює на сервері й потребує власних ліцензій (розділ 9).
- Повна незалежність від 1С — це окремий великий проєкт (власний сервер обліку та перенесення даних); інсталятор її не забезпечує.

## 2. Вимоги

| Компонент | Вимога |
|---|---|
| Робоче місце | Windows 10 або новіша, 64-розрядна. Windows 7/8.x не підтримуються (Electron 23+); інсталятор перевіряє номер збірки Windows і зупиняється з поясненням. |
| Мережа | Доступ із робочого місця до шлюзу Кермо (за замовчуванням порт 8480, змінюється в `gateway.config.json`). |
| Сервер | Запущений шлюз Кермо та сервер 1С; користувачі мають облікові записи 1С. |
| Права | Для встановлення «для поточного користувача» права адміністратора не потрібні; «для всіх користувачів» — потрібні. |

## 3. Артефакти

Збираються на сервері в `agent_work\release`:

| Файл | Призначення |
|---|---|
| `Kermo-Setup-0.1.0.exe` | інсталятор (майстер українською, тихий режим) |
| `Kermo-0.1.0-win-x64-portable.zip` | портативна збірка без встановлення |
| `SHA256SUMS.txt` | контрольні суми; перевірка: `Get-FileHash <файл> -Algorithm SHA256` |
| `verify.log`, `e2e_desktop.out` | протокол останньої перевірки на сервері |

Інсталятор **не підписано цифровим підписом**: під час першого запуску Windows SmartScreen може показати попередження про невідомого видавця. Варіанти: розгортання через групову політику/каталог, якому довіряють, або придбання сертифіката підпису коду (потрібне рішення власника).

## 4. Встановлення у майстрі

1. Запустіть `Kermo-Setup-0.1.0.exe`. Перша сторінка — ліцензійна довідка (потреба в ліцензіях 1С, сторонні компоненти).
2. Оберіть, для кого встановити: лише для мене чи для всіх користувачів комп’ютера (потрібні права адміністратора).
3. За потреби змініть папку встановлення.
4. Після встановлення в меню «Пуск» і на робочому столі з’являється ярлик «Кермо».
5. На екрані входу натисніть «Налаштування підключення» й вкажіть адресу сервера (її надає адміністратор), наприклад `http://192.168.0.10:8480`. Адреса запам’ятовується; пароль не зберігається ніколи.

## 5. Тиха установка та розгортання по мережі

```
Kermo-Setup-0.1.0.exe /S /SERVER=http://192.168.0.10:8480 /allusers
Kermo-Setup-0.1.0.exe /S /currentuser /D=C:\Apps\Kermo
```

- `/S` — без вікон; `/allusers` або `/currentuser` — режим встановлення; `/D=папка` — каталог (має бути останнім параметром, без лапок).
- `/SERVER=адреса` — записує адресу сервера для всіх користувачів комп’ютера в `%ProgramData%\Kermo\server.url`. Значення може бути в лапках; приймаються лише `http://` і `https://`.
- Пріоритет адреси в програмі: адреса, яку користувач вказав на екрані входу → аргумент запуску `--server=адреса` → `server.url` від інсталятора → сервер, що віддав інтерфейс (лише у браузері).
- Тиха установка програму **не запускає**.

## 6. Портативна збірка

Розпакуйте `Kermo-0.1.0-win-x64-portable.zip` у будь-яку папку й запустіть `Kermo\Kermo.exe`. Файл `portable.flag` поруч із програмою вмикає портативний режим: налаштування й журнали зберігаються в папці `data` поруч, а не в профілі користувача. Адресу сервера вкажіть на екрані входу або запускайте з `--server=адреса`.

## 7. Оновлення та видалення

- **Оновлення:** запустіть новий інсталятор поверх встановленого (у тому числі тихо). Старий деінсталятор спрацьовує автоматично, адреса сервера від інсталятора й налаштування користувача зберігаються. Автоматичне оновлення з сервера **не реалізовано**.
- **Видалення:** «Параметри → Програми» або `"<папка>\Uninstall Kermo.exe" /S`. Видаляються програма, ярлики, запис у «Програми та засоби» та `server.url`. Налаштування й журнали користувача (`%APPDATA%\Kermo`) лишаються — за потреби видаліть вручну.

## 8. Журнали й безпека

- Журнал: `%APPDATA%\Kermo\logs\kermo.log` (у портативному режимі — `data\logs`); відкрити папку можна з меню «Довідка → Відкрити папку журналів». Журнал не містить паролів.
- Інтерфейс вбудовано в програму; вікно працює в ізольованому режимі (`sandbox`, `contextIsolation`), без доступу до Node.js; дозволи на камеру, мікрофон тощо вимкнено; зовнішні посилання відкриваються в браузері; навігація поза вбудованим інтерфейсом блокується; політика безпеки вмісту обмежує скрипти власними.
- Прапорець `--remote-debugging-port` — стандартна можливість Chromium; його використовують лише автотести.
- Пароль користувача передається шлюзу під час входу й не зберігається ні програмою, ні шлюзом.

## 9. Ліцензії та залежності

Потрібні ліцензії (купуються окремо; «Кермо» їх не замінює):

| Що | Примітка |
|---|---|
| 1С:Підприємство 8.1 (сервер) | ліцензії на одночасні сеанси: кожен вхід у «Кермо» займає окремий сеанс 1С; шлюз не об’єднує користувачів в один сеанс. Ліміт сеансів шлюзу — параметр `maxSessions`: для робочої експлуатації виставляйте за кількістю придбаних ліцензій. |
| Microsoft SQL Server | СУБД системи обліку (зараз 2012, підтримка Microsoft закінчилась). |
| Windows Server та клієнтські ліцензії Microsoft | за політикою Microsoft. |

Вбудовані відкриті компоненти: Electron і Chromium (MIT, BSD-3 та інші; повні тексти в `LICENSE.electron.txt` і `LICENSES.chromium.html` у папці програми), React і Vite (MIT). Інструменти збірки: electron-builder (MIT), NSIS (zlib/libpng). «1С:Підприємство» — торгова марка відповідного правовласника.

## 10. Збірка з вихідних кодів (Windows)

Версії: Node.js 24.x, npm 11.x; Electron 44.8.0, electron-builder 26.15.3 (NSIS 3.0.4.1 завантажується electron-builder), React 19, Vite 8, TypeScript 7. Потрібен інтернет (завантаження Electron і NSIS із GitHub). Збірку виконано на Windows Server 2019 від імені адміністратора.

```
cd source\client
npm ci
npm run build
cd ..\desktop
npm ci
npm run prepare-client
npm run dist
```

Результат: `source\desktop\dist\Kermo-Setup-0.1.0.exe` і `dist\win-unpacked` (з нього робиться ZIP). Службові переклади повідомлень інсталятора (укр.) додає `scripts\patch-nsis-messages.mjs` перед кожною збіркою. На сервері все це виконує `source\desktop\scripts\build-windows.ps1`.

Фірмову графіку (значок, зображення майстра, ліцензійну довідку) вже збережено в `source\desktop\assets`; відтворити: `node scripts/render-brand.mjs /tmp/kermo-brand`, потім `uv run --with pillow python scripts/pack_assets.py /tmp/kermo-brand assets`.

## 11. Перевірки

| Перевірка | Файл | Що охоплює |
|---|---|---|
| Модульні тести оболонки | `source\desktop\test\config.test.js` | розбір і пріоритет адреси сервера |
| Розбір `/SERVER=` у NSIS | `scripts\test-nsis.ps1` | 7 випадків (лапки, регістр, зайві параметри, некоректні значення) на справжньому makensis |
| Перевірка на тестовій машині | `scripts\verify-windows.ps1` | тиха установка з `/SERVER=`, файли й версія exe, запис у «Програми та засоби», ярлики, програма проти копії бази (вхід, список, фільтр, картка, «Про систему»), оновлення поверх, тихе видалення, портативний режим |

Результати останнього прогону зберігаються на сервері в `agent_work\release\verify.log`.

## 12. Обмеження (чесно)

- Майстер установки перевірено лише в тихому режимі й за кодом; візуально його сторінки не оглядалися, тому текст і вигляд майстра ще треба переглянути на робочому місці.
- Не реалізовано: підпис коду, автооновлення, встановлення на Windows 7/8.x, збірки x86 і ARM.
- У властивостях Kermo.exe назва й опис латиницею («Kermo»).
- Запис, проведення й друк документів у програмі ще не підключено (див. «Про систему»).
- Перевірено на Windows Server 2019; клієнтські Windows 10/11 ще не перевірялися.
